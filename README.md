# wheremystuff

I really enjoyed using AI to create this project. I didn't know how detailed and cool ideas people could create simply by typing in questions and getting answers. 

The app is used to track your personal items that you find yourself missplacing on a day to day basis. I used ChatGPT to create the app and all of the neccessary functions. I had many issues throughout the process and used chat to trouble shoot them as well. You really have to play with it and ask it the right things in order to get the desired results.
